# KeenKeeper 🌟

**Stay Close to the People Who Matter**

KeenKeeper is a personal relationship tracking web application built to help you maintain meaningful connections with friends, family, and colleagues. It allows you to track your last interactions, set touchpoint goals, and log various communication types—all within a clean, modern, and highly responsive Figma-style user interface.

## 🌟 Core Features

* **Friends Dashboard:** Easily browse all your connections in a responsive grid layout. Each profile card displays a profile picture, current status, and a dynamic counter showing how long it has been since your last interaction.
* **Detailed Friend View:** Deep dive into specific connections to view interaction history, relationship goals, and access a quick **“Check-In”** feature to log calls, texts, or meetups.
* **Filtered Timeline:** Explore a complete history of your interactions. Filter activities by type (Call, Text, Video, or Meetup) to quickly analyze past communication.
* **Interaction Analytics:** Gain insights into your communication patterns through a beautiful, visual pie chart powered by **Recharts**.
* **Local Data Storage:** All your data and timeline history are securely saved in your browser using `localStorage`, keeping your information intact even after a refresh.
* **Responsive Experience:** Fully optimized for seamless performance across mobile, tablet, and desktop screens.
* **Custom 404 Page:** A clean, user-friendly error page for handling unknown routes gracefully.
